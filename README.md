# Where is it? — Крестики-нолики

Готовая игра для GitHub Pages. Все картинки и код находятся внутри архива. Внешние сервисы, шрифты и вход в аккаунт не нужны. Игра также открывается локально: распакуйте архив и откройте index.html.

## Загрузка через сайт GitHub
1. Создайте новый публичный репозиторий, например prepositions-game.
2. Распакуйте ZIP на компьютере.
3. В репозитории выберите Add file → Upload files (в пустом репозитории — uploading an existing file).
4. Перетащите ВСЁ содержимое распакованного архива: index.html, style.css, app.js, папку assets и остальные файлы. Не загружайте сам ZIP и не добавляйте лишнюю внешнюю папку. index.html должен находиться в корне репозитория.
5. Нажмите Commit changes.
6. Откройте Settings → Pages. В разделе Build and deployment выберите Source: Deploy from a branch, Branch: main, папку / (root). Нажмите Save.
7. Дождитесь публикации. Ссылка появится на странице Pages; обычно адрес выглядит как https://ВАШ-ЛОГИН.github.io/prepositions-game/ .

## Как играть
Игрок выбирает клетку и устно описывает картинку. Учитель или второй игрок нажимает «Верно» или «Ошибка». Ответы не распознаются автоматически. Побеждает тот, кто соберёт три своих знака в ряд. Подсказку и ответ можно скрыть. Новый раунд перемешивает картинки и сохраняет счёт.

Доступность самого GitHub Pages зависит от провайдера и региона; архив не требует доступа к ChatGPT.
